# Math Gesture Game 🎮✋

## Giới thiệu
Game học toán sử dụng nhận diện cử chỉ tay bằng camera.

## Công nghệ
- HTML/CSS/JS
- MediaPipe Hands
- Firebase Auth & Firestore

## Cách chạy
1. Mở link
2. Đăng nhập
3. Cho phép camera
4. Chơi game

## Tính năng
- Nhận diện số ngón tay
- Nhiều level
- Lưu lịch sử
- Thống kê điểm
